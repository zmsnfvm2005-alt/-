## 동작 방식
1. 매일 아침 새 세션이 자동으로 깨어남 (Routine).
2. 웹에서 오늘의 비즈니스 왕복 최저가(2인 기준)를 조사.
3. `price-history.json`에 기록하고 전일 대비 증감 + 목표가 도달 여부 계산.
4. 요약을 **휴대폰 푸시 + 이메일**로 발송 (목표가 도달·큰 폭 하락 등 중요한 변화가 있을 때 두 채널 모두 발송).
5. 알림에는 오늘 조건(날짜/좌석/인원) 그대로 검색되는 **스카이스캐너 예약 링크**가 항상 포함됨 (`search_links` 참고). 결제는 사용자가 직접 진행.

## 파일
