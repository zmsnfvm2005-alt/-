# ✈️ 신혼여행 항공권 가격 추적기

인천(ICN) 출발, **호주 시드니** 또는 **체코 프라하**행 **비즈니스** 왕복 항공권을
매일 자동으로 추적해서 **휴대폰 푸시**로 알려주는 세션입니다.

## 여행 조건
| 항목 | 값 |
|---|---|
| 출발 | 인천 (ICN) |
| 목적지 | 시드니(SYD) 또는 프라하(PRG) |
| 출발일 | 2026-03-20 |
| 귀국일 | 2026-03-30 (약 10일) |
| 좌석 | 비즈니스 |
| 인원 | 2명 (가격은 1인 왕복 기준 기록) |

> 10시간+ 장거리 + 공황장애 → 직항/경유 1회 이하, 넓고 프라이버시 좋은 좌석 우대.

## 동작 방식
1. 매일 아침 8시(KST) 자동으로 새 세션이 깨어남 (Routine).
2. 웹에서 오늘의 비즈니스 왕복 최저가를 조사.
3. `price-history.json`에 기록하고 전일 대비 증감을 계산.
4. 요약을 **휴대폰 푸시 알림**으로 발송 (하락 시 강조).

## 파일
- `price-history.json` — 매일 쌓이는 가격 기록 + 여행 조건 + 목표가.
- `daily-check-instructions.md` — 매일 세션이 따르는 실행 지침.

## 목표가 설정
`price-history.json`의 `targets`에 원하는 금액(KRW, 1인)을 넣으면
그 이하로 떨어질 때 알림에서 "🎯 목표가 도달"로 강조합니다. 예:
```json
"targets": { "SYD_krw_per_person": 3000000, "PRG_krw_per_person": 4500000 }
```

## 주의
가격은 웹 검색 기반 **추정치**입니다. 최종 결제 전 반드시 항공사·스카이스캐너에서
직접 확인하세요. 이 추적기는 예약을 대신 진행하지 않습니다(정보 제공 전용).
