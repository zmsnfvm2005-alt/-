# 신혼여행 항공권 추적 — 실행 지침 (v3: 매시간 실행 + 역대최저가 알림)

이 문서는 **매시간** 자동으로 깨어나는 세션이 따르는 지침입니다.
**2026-07-25 기준으로 추적 대상을 시드니·프라하 2개 노선으로 확정했습니다.**
마드리드·파리·바르셀로나는 조사 결과 탈락 — 사유는 `price-history.json`의
`considered_and_rejected`에 기록돼 있으니 재조사 대상에서 제외할 것.

## ⏱️ 실행 빈도와 알림 정책 (2026-07-26 변경)
매시간 실행되지만, **알림(푸시+이메일)은 "역대 최저가 갱신"일 때만 노터블하게 강조한다.**
- `history` 배열 전체(날짜 미지정 프로모션가 등 confidence:"low"는 제외)에서 각 노선의 지금까지 최저 `price_krw_2p`를 계산한다.
- 오늘 조사한 가격이 그 값보다 **낮으면(신뢰도 medium/high 기준)** → "🔻 역대 최저가 갱신!"으로 요약 첫 줄에 명확히 써서 노터블로 인식되게 한다.
- 갱신이 없으면 담백하게 기록만 하고 요약도 평이하게 쓴다 (매시간 알림 스팸 방지).
- 목표가(시드니 500만/프라하 900만) 이하 도달은 역대 최저 갱신 여부와 별개로 항상 최우선 강조.

## 여행 조건 (고정)
- 출발: 인천(ICN)
- 목적지: **시드니(SYD)** 와 **프라하(PRG)** 두 곳만 추적
- 출발일: 2026-03-20 / 귀국일: 2026-03-30 (왕복, 약 10일)
- 좌석: **비즈니스**
- 인원: 2명 (신혼여행) — **가격은 항상 2인 합산(KRW)** 으로 기록. 1인가만 나오면 반드시 2배 환산하고 그 사실을 note에 명시.
- 사용자는 공황장애가 있어 10시간+ 장거리 비행이 부담됨.

## 목표가 (targets, price-history.json 참조)
- 시드니: **2인 500만원**
- 프라하: **2인 900만원**
- 이 금액 이하로 떨어지면 알림에서 최우선으로 강조.

## ⚠️ 목표가 판정 규칙 (2026-07-26 사고 이후 추가)
"~원부터" 식 항공사 보도자료/이벤트 페이지 헤드라인 가격은 **날짜가 지정되지 않은 프로모션 최저가**일 뿐이며 실제 3/20~3/30 출발 가격과 무관할 수 있다. 실제로 아시아나 프라하 신규취항 "4,000,500원부터" 문구를 2배해 800만원으로 기록했다가, 사용자가 스카이스캐너에서 실제 날짜로 확인하니 1,200만원이 나온 사고가 있었다.
**따라서:**
- "목표가 도달" 판정은 **반드시 실제 출발/도착 날짜(2026-03-20/03-30)를 넣고 검색한 가격**에만 적용한다. Skyscanner/Kayak/항공사 예약엔진에서 날짜 지정 검색 결과가 이상적이다.
- 날짜 미지정 보도자료성 헤드라인가는 `confidence: "low"`와 함께 "날짜 미확인 프로모션가, 목표가 판정에 사용 안 함"이라고 note에 명시하고, 절대 "🎯 목표가 도달"로 표시하지 않는다.

## 노선별 특이사항 — 매일 반드시 확인
### 시드니 (SYD)
- 운항: 대한항공(KE) · 아시아나(OZ) · 콴타스(QF) 3개사 직항 경쟁.
- 좌석 프라이버시 순위: 콴타스(1-2-1 스태거드, 최고) > 대한항공(Apex Suite, 파티션) > 아시아나(A350, 가장 개방적). 도어형 좌석은 없음.
- 3사 모두 최저가를 비교해서 기록할 것.

### 프라하 (PRG)
- 운항: 대한항공(KE969/970) + 아시아나(2025년 신규 취항, 편명 미확정 — 검색해서 확인).
- **가장 중요:** 이 노선은 787-9와 787-10이 혼용 투입됨. **787-10은 도어형 스위트 + 커플/더블베드형 좌석**이 있어 공황장애 고려 시 최우선. 오늘 검색 시점에 787-10이 배정된 스케줄이 있는지, 있다면 어떤 요일/편명인지 확인해서 note에 남길 것.
- 체코항공은 2024년 폐업 — 더 이상 옵션 아님.

## 사용자에게 보낼 요약 (푸시 알림 + 이메일 본문)
- 이 루틴은 push와 email 채널이 모두 켜져 있다. 시스템이 "노터블(noteworthy)"하다고 판단한 실행에 한해 두 채널로 동시 발송되므로, **목표가 도달·큰 폭 하락·787-10 발견처럼 실제로 중요한 변화가 있을 땐 요약 첫 문장에서 명확히 그 사실을 알 수 있게** 써서 노터블로 인식되게 한다. 변화가 없는 날은 담백하게 현황만 적어도 된다.
- 한국어, 200자 이내 한 줄. 이모지 최소. **가격은 항상 2인 합산으로 표기.**
- **항상 예약 링크를 포함한다.** `price-history.json`의 `search_links.SYD` / `search_links.PRG` (스카이스캐너, 오늘 날짜/좌석/인원 그대로 검색되는 라이브 링크)를 그대로 붙인다. 특정 항공사 특가를 발견했으면 해당 항공사 예약 페이지(`search_links.SYD_airline_pages` / `PRG_airline_pages`)도 함께.
- 형식 예 (변화 없는 날):
  `[항공권] 시드니 445만(▼12만) · 프라하 1,120만(→). 목표가(500/900만)까지 시드니 -55만 남음\n예약검색: [시드니] <SYD 링크> / [프라하] <PRG 링크>`
- 목표가 도달 시: `🎯 목표가 도달! 시드니 490만(2인) — 지금 예약 검색: <SYD 링크>` 형태로 최우선 강조.
- 프라하 787-10 배정을 새로 발견하면 반드시 언급하고 해당 편 예약 링크도 포함: `프라하 787-10(커플석) 스케줄 발견! 예약 검색: <PRG 링크>`
- 조사 실패 시: `[항공권] 오늘 시세 조회 실패 — 스카이스캐너에서 직접 확인 필요: <SYD 링크> / <PRG 링크>`.
- 링크는 어디까지나 "오늘 조건 그대로 검색"으로 안내하는 것이며, 결제는 사용자가 직접 진행한다는 점을 잊지 말 것 (예약을 대신 진행하지 않음).
