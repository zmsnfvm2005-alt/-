# 신혼여행 항공권 매일 추적 — 실행 지침 (v2: 시드니 vs 프라하)

이 문서는 매일 자동으로 깨어나는 세션이 따르는 지침입니다.
**2026-07-25 기준으로 추적 대상을 시드니·프라하 2개 노선으로 확정했습니다.**
마드리드·파리·바르셀로나는 조사 결과 탈락 — 사유는 `price-history.json`의
`considered_and_rejected`에 기록돼 있으니 재조사 대상에서 제외할 것.

## 여행 조건 (고정)
- 출발: 인천(ICN)
- 목적지: **시드니(SYD)** 와 **프라하(PRG)** 두 곳만 추적
- 출발일: 2026-03-20 / 귀국일: 2026-03-30 (왕복, 약 10일)
- 좌석: **비즈니스**
- 인원: 2명 (신혼여행) — **가격은 항상 2인 합산(KRW)** 으로 기록. 1인가만 나오면 반드시 2배 환산하고 그 사실을 note에 명시.
- 사용자는 공황장애가 있어 10시간+ 장거리 비행이 부담됨.

## 목표가 (targets, price-history.json 참조)
- 시드니: **2인 500만원**
- 프라하: **2인 900만원**
- 이 금액 이하로 떨어지면 알림에서 최우선으로 강조.

## 노선별 특이사항 — 매일 반드시 확인
### 시드니 (SYD)
- 운항: 대한항공(KE) · 아시아나(OZ) · 콴타스(QF) 3개사 직항 경쟁.
- 좌석 프라이버시 순위: 콴타스(1-2-1 스태거드, 최고) > 대한항공(Apex Suite, 파티션) > 아시아나(A350, 가장 개방적). 도어형 좌석은 없음.
- 3사 모두 최저가를 비교해서 기록할 것.

### 프라하 (PRG)
- 운항: 대한항공(KE969/970) + 아시아나(2025년 신규 취항, 편명 미확정 — 검색해서 확인).
- **가장 중요:** 이 노선은 787-9와 787-10이 혼용 투입됨. **787-10은 도어형 스위트 + 커플/더블베드형 좌석**이 있어 공황장애 고려 시 최우선. 오늘 검색 시점에 787-10이 배정된 스케줄이 있는지, 있다면 어떤 요일/편명인지 확인해서 note에 남길 것.
- 체코항공은 2024년 폐업 — 더 이상 옵션 아님.

## 매일 할 일
1. 브랜치 체크아웃:
   `git fetch origin claude/honeymoon-flight-price-tracker-df0d95`
   `git checkout claude/honeymoon-flight-price-tracker-df0d95`
2. `flight-tracker/price-history.json` 읽기. 마지막 기록가와 `targets` 확인.
3. WebSearch로 오늘 시세 조사 (2인 기준으로 검색어에 명시):
   - "인천 시드니 비즈니스 항공권 2인 왕복 2026년 3월 가격"
   - "ICN SYD business class 2 adults round trip March 2026 skyscanner kayak"
   - "인천 프라하 비즈니스 항공권 2인 왕복 2026년 3월 대한항공"
   - "ICN PRG business class 2 adults round trip March 2026 korean air prestige 787-10"
   - 필요 시 skyscanner / kayak / trip.com / koreanair.com / flyasiana.com 을 WebFetch로 열어 확인.
4. 각 노선의 **최저 비즈니스 왕복가(2인 합산, KRW)** 와 항공사/경유/신뢰도를 뽑는다.
5. `history` 배열 끝에 오늘 날짜 항목을 추가한다 (기존 형식과 동일, `price_krw_2p` 필드 사용).
6. 직전 기록 대비 변화 계산 (2인 합산 기준 증감액/증감률), 목표가 이하 도달 여부 확인.
7. 커밋 & 푸시:
   `git add flight-tracker/price-history.json`
   `git commit -m "chore(flight-tracker): YYYY-MM-DD 시세 업데이트"`
   `git push -u origin claude/honeymoon-flight-price-tracker-df0d95`
   (실패 시 2s/4s/8s/16s 백오프로 최대 4회 재시도)

## 사용자에게 보낼 요약 (푸시 알림 본문)
- 한국어, 200자 이내 한 줄. 이모지 최소. **가격은 항상 2인 합산으로 표기.**
- 형식 예:
  `[항공권] 시드니 445만(▼12만) · 프라하 1,120만(→). 목표가(500/900만)까지 시드니 -55만 남음`
- 하락 시 "하락"/"↓"를 앞쪽에 강조. 목표가 이하 도달 시 "🎯 목표가 도달" 최우선.
- 프라하 787-10 배정을 새로 발견하면 반드시 언급: `프라하 787-10(커플석) 스케줄 발견!`
- 조사 실패 시: `[항공권] 오늘 시세 조회 실패 — 스카이스캐너에서 직접 확인 필요`.

- 마드리드/파리/바르셀로나는 재조사하지 말 것 (탈락 사유가 price-history.json에 기록됨).
